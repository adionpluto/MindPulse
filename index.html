How MindPulse Works

1. Data Collection

Participants anonymously answer questions regarding stress, mood, sleep, focus, and coping strategies via Google Forms.

2. Welfare Evaluation

The automated assessment engine computes 5 psychological dimensions, maps behavioural personas, and detects acute stress risks.

3. Automated Publishing

Each response automatically builds a tailored HTML report with Chart.js analytics and deploys live to GitHub Pages via GitHub Actions.
