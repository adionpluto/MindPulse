# Psyche-Reports: Psychological Welfare Assessment Platform

> A school project focused on evaluating individual emotional wellbeing, behavior patterns, and stress metrics to deliver personalized self-improvement reports.

---

## 📌 Project Overview
This project collects survey responses from participants via a Google Form, analyzes key psychological indicators (behavioral traits, dominant emotions, and stress levels), and generates tailored HTML reports hosted on GitHub Pages.

### Objectives
* **Analyze** behavioral tendencies and emotional drivers from survey data.
* **Quantify** stress and anxiety indicators for individual participants.
* **Provide** actionable, personalized recommendations and coping strategies.
* **Host** individual digital reports seamlessly using static Web technologies.

---

## ⚙️ How It Works
1. **Data Collection:** Participants fill out an anonymous psychological evaluation form.
2. **Evaluation:** Answers are assessed to identify behavioral patterns and stress levels.
3. **Report Generation:** Individual static HTML reports are created with specific insights and recommendations.
4. **Deployment:** Web reports are published live on GitHub Pages.
